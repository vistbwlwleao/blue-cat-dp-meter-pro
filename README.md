## Overview

Blue Cat DP Meter Pro provides comprehensive audio level analysis with peak, RMS, LUFS, and true-peak measurement in one plugin, essential for broadcast-compliant loudness management.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat DP Meter Pro** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **LUFS Metering** | Integrated, short-term, and momentary LUFS measurement per EBU R128 |
| **True Peak** | Inter-sample peak detection for accurate ISP compliance reporting |
| **Peak Hold** | Configurable peak hold and automatic clip reset functionality |
| **Logging** | Continuous level logging with export to CSV for analysis |
